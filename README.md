# Mensch ärgere Dich nicht – finale Regelkorrektur

Diese Version behält Design, Layout und die originale Board-SVG unverändert.

Zusätzliche Regelkorrektur:
- Sobald ein Spieler mindestens eine Figur im Ziel hat und alle noch nicht im Ziel befindlichen Figuren wieder im Haus sind, erhält er automatisch wieder bis zu 3 Würfe, um eine 6 zum Herauskommen zu bekommen.
- Befindet sich noch mindestens eine eigene Figur auf der Laufbahn, gilt diese automatische 3-Wurf-Hausregel nicht.
- Eine gewürfelte 6 bringt dann eine Hausfigur heraus bzw. macht das A-Feld gemäß den bestehenden Regeln frei.
